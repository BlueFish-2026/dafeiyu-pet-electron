一个**完全不依赖 DSH** 的桌面宠物，能自己浮在桌面上，带余额显示和两种提醒。

素材和动画来自开源项目 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet)（106 个透明动画），
但驱动它的宿主是本项目自己写的 —— 所以它不再需要装 DSH 客户端，也不怕 DSH 更新后插件失效。

## 怎么用

| 想干什么 | 怎么做 |
|---|---|
| 让宠物出现 | 双击桌面上的 **大肥鱼桌宠**（快捷方式） |
| 改提醒 / 改外观 | 双击 **大肥鱼桌宠-设置**，或右键托盘图标 → 打开设置 |
| 调大小 / 重启 / 关掉宠物 | **在宠物身上点右键** → 见下 |

双击 **大肥鱼桌宠** 不会弹出任何命令行窗口，等两三秒宠物就浮在桌面上了（默认右上角）。
快捷方式在项目文件夹里也有一份，名字一样，双击哪个都行。

### 在宠物身上右键

**日常所有操作都在这里**，菜单从上到下依次是：

```
打开设置页 / 查看余额 / 回到初始位置
调整大小（现在 N）  ▸   小一点 / 大一点 / 恢复默认（462）
久坐提醒            ▸   ● 开启久坐提醒 / 重置久坐计时 / —— 间隔时长 —— / ●30 ○45 ○60 ○90 分钟
提示开关            ▸   ● 定时提醒 / ● 显示余额 / ● 系统通知
重启大肥鱼
退出大肥鱼
动作                ▸   106 个动画，按类别分（上游自带）
```

> **「久坐提醒 ▸」「提示开关 ▸」是分组，点开才有子项** —— 它们不是开关本身，是那几个开关的归组。
>
> **原版菜单里的「碎碎念」「对话」已被摘掉**：这两项都要大模型生成内容，
> 而独立版没有接大模型（源码里直接返回「不支持」），留着只会让人点了以为坏了。

- **`●` / `○` 就是开关状态**　● = 开，○ = 关。点一下即刻生效、不用保存。
  （菜单是小窗口里的网页画面，画不出系统那种勾选框，所以用圆点表示。）
- **调整大小 ▸**　点一下改一档（约 ±15%），宠物会闪一下再回来 —— 这是在按新尺寸重建窗口，正常现象。
  标题上的数字就是**当前大小**。想填精确数值就去设置页的「宠物大小」（80～900）。
- **久坐提醒 ▸**　开关、间隔时长都在这里；「重置久坐计时」点了就把本次就座时间归零、从此刻重新计时
  （角标会先消失，满 1 分钟后再出现，正常）。
- **提示开关 ▸**　定时提醒 / 显示余额 / 系统通知 三个开关。
- **打开设置页**　打开网页设置页 —— 要打字的项（API Key、提醒文案、离开阈值、提醒时间条目）都在那。
- **重启大肥鱼**　把宠物整个重开一遍（会有两三秒空白，然后重新出现在桌面上）。
- **退出大肥鱼**　点了就整个关掉。

### 托盘只是「保命通道」

托盘（屏幕右下角的大肥鱼图标）只留了 4 项，都是**宠物窗口做不到**的事：

```
大肥鱼桌宠                     ← 标题，点不动
─────────────────────────
打开设置…                      ← 宠物被拖到屏幕外找不着时的兜底入口
─────────────────────────
重启大肥鱼
退出大肥鱼
```

> 双击托盘图标 = 直接打开设置页。

> **为什么日常开关搬到了宠物右键、托盘只剩 4 项**：菜单是画在宠物窗口里的，窗口比宠物大一圈、
> 但依然有限；默认情况下足够了，改到宠物右键是为了**让所有开关集中在一处**（不用"想调久坐时长 →
> 得去托盘翻"）。托盘留着这三件事：打开设置（兜底）、重启、退出 —— 这三件**必须由主程序来做**，
> 宠物窗口那层做不到。

> **为什么现在用快捷方式，而不是 `.vbs` / `.bat` 脚本**：两条路都试过，都不行 ——
> 批处理是控制台程序，Windows 一定会给它开一个黑窗口；而 `.vbs` 会被**火绒误杀**。
> 实测记录（火绒安全日志，2026-09-30）：
>
> ```
> 病毒名 : TrojanDownloader/VBS.Agent.dd
> 文件   : E:\WB\日常\桌宠\dsh-pet-standalone\大肥鱼桌宠.vbs   （隔离区 sha1 6BBCA03E…）
> 文件   : C:\Users\庄润杰\Desktop\大肥鱼桌宠.vbs             （同上）
> 时间   : 2026-09-30 16:23:32 / 16:23:47
> ```
>
> 原因是启发式：那个脚本会「用 shell 启动一个程序、该程序再去连本地网络」，形状和木马下载器
> 一模一样，杀软宁可错杀 —— **它把脚本文件直接删了**（所以双击时文件早已不存在，表现为"打不开"）。
> 快捷方式 `.lnk` 是二进制文件、里面没有一行脚本，对杀软就是一个普通程序图标，所以改用它。
> **别再改回脚本。**

> ⚠️ **火绒弹窗说发现病毒怎么办**：**是误报，不用管**。被点名的是我早期写的那几个 `.vbs`
> 启动脚本（现在已经彻底删除，不再使用），宠物程序本体 `bin\electron\electron.exe`
> **从未被报过**。你在火绒日志/隔离区里看到的 `TrojanDownloader/VBS.Agent.dd`
> 就是这几条，可以直接**清除 / 不恢复**。想彻底别再看到，就把项目文件夹加进火绒的信任区
> （火绒 → 安全工具 → 信任区 → 添加目录 → `E:\WB\日常\桌宠\dsh-pet-standalone`）。

> 宠物只在你双击启动后才在。关掉程序 = 没有提醒。想让开机就自动出现，**最省事**的办法：
> 打开设置页 →「外观与通知」→ 打开「开机自启」开关，它会自动写系统登录启动项（关掉开关即移除）。
> 想手动弄也行：把桌面上的 **大肥鱼桌宠** 快捷方式复制进 `shell:startup` 文件夹即可（Win+R 输入 `shell:startup` 回车）。

> ⚠️ 桌面上另有一个 `启动大肥鱼.vbs`，那是早期自动桌宠（Qt 版）留下的，跟本项目无关，别点错。

> `_debug\` 里的三个 bat 是**排错工具**，平时用不到。只有宠物起不来时去双击它们，
> 才能看到控制台输出。它们的正文一律纯 ASCII（英文提示），这是刻意的：中文 bat 会被
> Windows 命令行的编码处理搞崩（表现为「'exist' 不是内部或外部命令」）。中文界面都在设置网页里。

### 万一宠物没出现

**第一步：看 `data\host.log` 有没有新的时间戳。** 双击后等 5 秒，看文件最后一行是不是刚才的时间。

- **完全没有新行** → 程序根本没被启动起来，九成是**安全软件拦了**。去火绒 → 安全日志看看有没有
  关于 `electron.exe` 的拦截记录；有的话把它**允许 / 信任**，或直接把项目文件夹加进信任区。
  排除安全软件后，还可以双击 `_debug\` 里的 bat 看控制台报什么错。
- **有新行** → 继续看里面有没有这一行：

```
渲染进程已连上并取走配置 —— 宠物窗口应当已经创建
```

  - **有这一行** → 程序和渲染进程都是好的，宠物确实被创建了，只是你没看到它。常见原因：被全屏
    程序（游戏、全屏视频、投影/演示模式）盖住了，或者它被拖到屏幕边界外。关掉重开即可复位。
  - **没有这一行** → 渲染进程没起来。把 `data\helper.log` 的最后几行发出来就能定位。

同样的宠物只允许存在一只：重复双击启动不会出现第二只，多余的会自己退出。

## 它能做什么

- **106 个动画**：待机呼吸、打瞌睡、写代码、涮火锅、跳舞、放烟花…… 自己会时不时换一个
- **能互动**：鼠标点它有反应、能拖能甩、右键能点播动作
- **余额显示**：读 DeepSeek 官方接口，按余额多少播不同动画、头顶弹气泡
- **久坐提醒**：连续用电脑满设定时长就提醒你起来动动；**头顶常驻一个计时角标**，
  实时显示「已坐 M/N 分」，到点整颗转红
- **定时提醒**：到点提醒你开会、吃药、接孩子……支持每天 / **工作日（跳节假日、认调休补班）** / 自定义星期 / 仅一次

## 提醒怎么配

**开关类**（开不开、多少分钟、哪个角落）→ **在宠物身上点右键**，
「久坐提醒 ▸」「提示开关 ▸」两个分组里全都有，点一下就生效。
**要打字类**（定时提醒的条目、自定义文案、API Key）→ 双击「大肥鱼桌宠-设置」，
或右键宠物 →「打开设置页」，在网页里改，改完点**保存**。

> 它是个网址快捷方式（`.url`），点开会用浏览器打开 `http://127.0.0.1:34517/admin`。
> 所以**宠物得先启动着**，设置页才打得开。
>
> ⚠️ 地址**必须带 `/admin`** —— `http://127.0.0.1:34517` 是根路径，没有页面（只会显示一行小白字）。
> 记不住就用托盘：**右键右下角托盘图标 → 打开设置…**，它会自己把完整地址送到浏览器。
> （新版已加自动跳转：只输根地址也会跳到设置页。旧版本需要重启宠物才生效。）

**久坐提醒**关心三个数：

- **坐多久提醒一次** —— 默认 45 分钟
- **离开多久算休息过** —— 默认 5 分钟。中途去接水/上厕所超过这个时长，计时会归零重来
  （靠系统级的键鼠空闲检测，不需要你手动点任何按钮）
- **不理会时多久再催** —— 默认 10 分钟。你还不起来它就再提醒一次

**定时提醒**每条都要选一个「重复规则」，四种可选：

| 规则 | 含义 |
|---|---|
| **每天** | 天天都提醒 |
| **工作日** | 只在工作日提醒 —— **自动跳过法定节假日**，**调休补班的周末照样提醒** |
| **自定义星期** | 自己勾星期几（比如只勾周一、周三）；切过来默认勾周一到周五 |
| **仅一次** | 提醒过一次就永久作废，不重复 |

> 「工作日」依赖联网获取节假日日历（首次自动拉取，之后本地缓存 7 天）。
> **断网时会自动降级成「周一～周五」**，提醒不会因此失灵。
> 中国的调休规则每年由国务院发布，所以当年数据在年初可能还没出 —— 那时也会先按星期算，等发布了自动补上。


**「人还在不在电脑前」是自动判断的**，所以：你起来走了，它不会傻乎乎地继续计时；
你回来坐下，它从头算 45 分钟。

**头顶那个计时角标**（跟老版大肥鱼一样）：

```
                                  ⏱ 已坐 23/45 分      ← 蓝色，正常计时中
                                  ⏱ 已坐 52/45 分      ← 变红 = 超时了，该起来了
```

- **坐满 1 分钟才现身**（刚坐下不会立刻冒出来 —— 这是跟老版一样的规矩）
- 位置在宠物**头顶正上方居中**。头顶本来会被气泡占，所以角标往上抬了一格，
  和气泡**上下叠放、不会打架**：有气泡时角标在气泡正上方，没气泡时就是头顶上方的悬浮小标
- 数字是**实时**的，每分钟自己跳一格
- 中途离开电脑超过「离开多久算休息过」这个时长，角标会**自己消失**，回来重新计时
- 把**久坐提醒**关掉，角标也跟着消失（它是久坐提醒的一部分）
- 角标是**矢量画的**（圆角胶囊 + 矢量小闹钟，实时绘制，不是图片）—— 放多大都不会糊，不存在「分辨率」问题
- 宠物大小改了，角标会跟着一起**等比缩放**（角标尺寸 = 宠物大小 × 固定系数，比例恒定）。
  它**没有独立的大小设置**，想让角标更大就把宠物调大
- 计时本身只在本机算，**不联网、不上传**

**定时提醒**点「+ 添加一条」，填时间、内容，选「每天」或「仅一次」。

> 两种提醒都会：宠物播一个专属动画 + 头顶弹气泡 + （可选）右下角系统通知。

## 余额的密钥

第一次启动会**自动从 DSH 里读取**你已有的 DeepSeek 密钥，所以通常不用管。

如果你卸载了 DSH、或者想换成别的密钥，在设置页的「DeepSeek API Key」里填一个就行。
密钥只存在本机 `config\user-config.json`，不会外传。

## 出问题了看哪里

| 文件 | 内容 |
|---|---|
| `data\host.log` | 主程序日志（启动过程、提醒触发、报错） |
| `data\helper.log` | 宠物渲染进程日志（窗口、DPI、动画） |
| `config\user-config.json` | 你的全部设置（改坏了可以删掉，会自动重建默认值） |

**宠物没出现**：先看 `data\host.log` 最后几行。如果提示「找不到 Electron 运行时」，
说明项目文件不完整，重新解压一遍整个文件夹。

**改设置后宠物没了**：设置里改了「宠物大小」会让渲染进程重启，等两三秒就回来了。

## 关于更新

`assets\` 和 `pet\` 来自 dsh-pet 项目。如果作者以后更新了动画素材，
可以把新版包里的 `assets\webm\` 覆盖过来。

`pet\` 里**只有两个文件**是动过的：

| 文件 | 动了什么 | 为什么必须改这里 |
|---|---|---|
| `pet\sprite.js` | 右键菜单：首项改名「打开设置页」、摘掉「碎碎念/对话」；加 调整大小 / **久坐提醒（开关·间隔·重置）** / **提示开关（定时·余额·通知）** / 重启 / 退出 | 菜单项的表是硬编码在这个文件里的，宿主侧注入不进去 |
| `pet\events.js` | 头顶久坐计时角标（挂 DOM + 每秒取一次计时） | 宠物 DOM 由 sprite.js 建、轮询由这里组装，同样没有外部注入点 |

两处改动都由 `..\_dsh_probe\apply_pet_patch.py` 统一管理（幂等：已经打过就跳过；
检测到旧版块会先剥离再重打；**锚点对不上就报错退出，绝不瞎改**）。
**上游一旦刷新 `pet\`，重跑一次这个脚本即可全部恢复**，不用手工改代码。
上游原始文件留档在 `..\_dsh_probe\_pet_baseline\`，随时能 diff。

`host\`、`web\`、两个入口文件（`.lnk` / `.url`）和 `_debug\` 里的 bat 是本项目自己的实现，与上游无关。
